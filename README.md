## 🛠 Kỹ Năng Tiêu Biểu
*   **Ngôn ngữ & Nền tảng:** Lập trình C (Bare-metal), RTOS / Hệ điều hành nhúng.
*   **Vi điều khiển (MCU):** Dòng STM32 (vd: STM32F411), ESP32 (vd: ESP32-C3), Silicon Labs (EFR32).
*   **Giao thức & Phần cứng:** Mạng không dây Zigbee, xử lý ngắt (Interrupts), GPIO, tích hợp cảm biến (MAX30102, cảm biến nhiệt độ nội).
*   **Kỹ năng mềm:** Đọc hiểu tài liệu kỹ thuật, thuyết trình chuyên ngành bằng tiếng Nhật.
